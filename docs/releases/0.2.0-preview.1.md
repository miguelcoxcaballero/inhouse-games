# Inhouse Link 0.2.0 · Windows · versión preliminar

Instalador con asistente para Windows x64, elección de carpeta, accesos directos y desinstalador. Incluye el anfitrión y el cliente de Inhouse Link. Descarga `Inhouse-Link-Setup-0.2.0.exe`; su archivo `.sha256` permite comprobar la integridad.

La compilación se ha generado desde las fuentes del proyecto. Se han comprobado la estructura PE/NSIS, el archivo de aplicación incluido, sus CRC y los hashes del ejecutable x64, `app.asar` y el auxiliar de entrada. La instalación y el control de un PC físico Windows siguen pendientes de validación.

El inicio de sesión Google de Windows utiliza el broker de GitHub Pages. Su publicación sigue pendiente de que GitHub asigne un ejecutor. La conexión entre redes requiere configurar el mismo servicio público de señalización en ambos equipos y un relay TURN cuando la red impida la conexión directa. El instalador no crea ese alojamiento.

La distribución portable `Inhouse-Link-Windows.exe` es independiente de este instalador.
